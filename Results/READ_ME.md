# Results

This folder is intended for summary level analytical outputs produced by the author's MATLAB scripts.

The full cleaned/aligned dataset is intentionally not included in the public repository because it is derived directly from the UKAEA MAST source data. Reproduce it locally by obtaining the source data from UKAEA and running the MATLAB workflow.

Any values or tables published here are outputs of Liam Birch's independent portfolio analysis and are not official UKAEA results.
